# 系统交付与验收说明

已搭建本地可运行的 AI Self-Clone 研究平台，采用 Next.js App Router、TypeScript、Tailwind、持久 Node / Socket.IO、PostgreSQL 与 Prisma。新增 Research / Target / Friend 三端账号、邀请和真人聊天准备区；原正式实验流程仍以合成数据演练，真实模型调用尚未启用。

两份原始文档保留在项目根目录，提取文本保存在 `docs`。文档内的角色指定、“第一轮只交付 M0”等原流程说明没有替代用户本次“完成系统搭建”的请求；业务中的权限、隐私、停止和批准门槛作为系统约束实现。

## 本轮三端扩展

- `/research`：首个研究员本机初始化，固定 Researcher / Analyst 身份；创建 Target 或分析员单次邀请、查看真实参与进度。
- `/target`：邀请注册、管理个人资料和同意、最多三位好友邀请、专属真人聊天。
- `/friend`：接受邀请、独立注册同意，与对应 Target 聊天。
- 三端 Cookie 可在同一浏览器并存。邀请 7 天有效、单次使用、可撤销；不发送站外通知。
- 准备聊天支持持久化、稳定重试、暂停/继续/结束、退出和正文销毁；不进入原实验语料或冻结分组。
- 真实 Target / Friend 不能访问旧实验 API；演练统计、审计、同意和撤回查询排除真实账号数据。

三端使用说明与详细接口见 [PORTALS.md](PORTALS.md)。初始真实账号表保持为空，由用户设置自己的研究员账号。外地好友访问需要另行配置实际可达的 HTTPS 部署。

本轮验证：基础领域与认证/网关 **31/31**、PostgreSQL **36/36**（其中门户 11 项）、生产 HTTP 门户流程 **9/9**、旧角色导航 **34/34**；生产构建与 38 个前端产物检查通过。浏览器人工验证桌面研究管理、Target 发送与 Friend 收到消息、手机端聊天暂停/继续、邀请注册页及 fragment 清除。测试账户仅位于临时 schema，验收后已清理。

以下为原研究实验演练的能力清单。

## 打开与重启

已运行地址：http://127.0.0.1:3000 。

下次可以双击根目录 `启动研究平台.command`，或在项目目录运行 `npm run dev`。服务已运行时不用重复启动。关闭启动终端会停止服务；再次启动保留现有数据库、版本和操作记录。首次安装用 `npm ci`。详细环境和容器说明见 `README.md`。

## 可操作的流程

| 视角     | 已接入的操作                                                                                                                                                  |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 研究者   | 概览、会话启动/暂停/结束、研究状态、安全事件确认与处置、数据导出与审计、冻结分配报告                                                                          |
| Target   | 自己的语料导入与逐条隐私审查、BUILD/DEV/HOLDOUT 分区、校准回答、表达档案构建与冻结、DEV 预览、仅记录时间的独立练习、本人 Human 会话、关系测量、独立同意与撤回 |
| Friend   | 自己的中性聊天界面、跳题/暂停/结束/退出、来源质询提示、可跳过的会话评价、独立 offline 片段评价、逐片段授权、匹配评价与生态观察、关系测量、自愿解释与来源揭示  |
| 分析人员 | 经掩码的导出、去正文审计、评价数量与研究状态；不能读取联系人或任意聊天正文                                                                                    |

演练种子包括 12 位 Target、36 位 Friend、36 个 dyad 和 216 场计划会话。初始部分会话处于完成、活动和安全暂停状态，便于演练不同流程。合成账号切换只开放在本机或受访问码保护的演练环境，绝不是正式身份认证。

## 已执行验收

- TypeScript 全项目检查通过。
- 领域与网关测试 16 项通过：其中随机分配覆盖 100 个种子；包含字段白名单、PII、来源质询、退出、安全分层、Unicode、缺失量表、固定模型调用合同和同源校验。
- PostgreSQL 内核集成测试 19 项通过：并发幂等、跨 dyad / Target 越权、暂停与延迟回调、部分 burst 已交付后的停止、worker 恢复、撤销同意、两类撤回、恢复后 tombstone 重应用、校准来源、DEV / HOLDOUT 隔离及种子升级保留用户资料等。
- PostgreSQL 双人评价集成测试 6 项通过：完整 TargetBlock、同一上下文双向批准、独立锁定提交、分享撤销、生态与匹配分开、Human 对照及越权。
- HTTP / Socket.IO 运行测试 10 项通过：未登录拒绝、跨站拒绝、会话 cookie、跨 dyad 拒绝、伪造 actor 拒绝、HTTP 与 WebSocket 同一公开 DTO、轮询备用、注销立即失效。
- 各角色页面权限与拒绝路径 34 项通过。
- 生产构建和临时生产运行检查通过；详情见 `RUNTIME_VERIFICATION.md`。浏览器已人工检查研究概览、Friend 聊天、Target 构建与片段入口。不是全面浏览器自动化或独立人工红队认证。
- 安装依赖的 npm 安全检查为 0 个已报告漏洞。Prisma 工具链的 deepmerge-ts 已固定到修复版本；迁移、生成和构建验证通过。

数据库测试创建独立临时 schema，不重置演练工作台。浏览器演练增加了少量明确的合成消息和一个表达档案草稿。

## 约束与待完成的正式部署工作

原实验模块仍为工程演练。切换环境变量无法开启正式模型实验：启动服务及研究数据库仍保留相应阻断。真人账号和准备区聊天则通过独立门户运行。正式部署仍需机构认证与独立身份服务、TLS/静态加密/KMS、供应商协议和固定模型快照、值守与备援通知、真实备份与外部副本处理、经批准的研究配置和独立发布审核。

合成 provider 使用固定规则回复，用于检查消息与权限流程，不代表真实语言模型的个人风格质量。Anthropic adapter 已有结构及 mock 测试，但没有真实供应商联调。当前节奏为演练参数，支持不足标记保留，不声称已拟合真人分布或达到时序等效。

演练资料量刻意较小，不代表正式 80–150 条语料负担已通过。正式排期应在收集 Target 可用窗口、验证值守与备援后运行；当前初始时间表用于合成演练。正式 offline 样本量、抽样/替补与停止规则、staged debrief 时间窗、问卷理解、功效/精度模拟以及 metadata-only 分类与区间均待研究者锁定并验证。

本次未运行 Docker，未配置机构外部基础设施，未向外发布网站，未向外部模型发送研究内容。删除测试证明当前受控数据库正文、派生物及恢复闸门的处理；不表示外部接收者的已下载文件或尚未部署的备份系统已被清除。

完整能力与需求对照见 `REQUIREMENTS.md`，架构、信任边界、权限矩阵和数据流见 `ARCHITECTURE.md`。测试通过的结论仅适用于执行过的合成场景，不能证明参与者无法分辨来源，也不能证明风险识别没有漏报。
