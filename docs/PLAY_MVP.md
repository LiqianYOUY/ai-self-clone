# 五轮文字盲测

本轮优化在现有项目中加入可独立使用的文字游戏。保留原研究和准备聊天的行为，游戏资料、消息及结果不读取或写入原研究语料、正式实验或准备聊天。

## 页面和流程

- `/`：游戏介绍和主要入口；原三个门户作为次要入口。
- `/play`：主持人注册/登录、分身档案、上线、邀请、本人回复台、统计。
- `/play/join#token=…`：朋友邀请预览、昵称与玩法说明。页面读取邀请后清除地址栏令牌。
- `/play/room/[id]`：朋友五轮文字聊天、猜测和揭晓。

朋友不用账号。一次性邀请换取绑定房间的 HttpOnly cookie，原始邀请令牌不存入数据库。主持人复用 Target 账号会话；自助注册的游戏账号不自动加入研究名单。

每局由服务端等概率选择 HUMAN/AI，并保存分身资料快照。朋友先问、来源后答，累计五组完整对话后可提交猜测。刷新不会重抽身份；同一消息的网络重试不会重复入库；重复猜测不会改写答案。消息和结果由 Postgres 持久保存。

主持人一次只开放一个未结束的房间，游戏页面每十秒发送在线心跳。离线达到服务端阈值、取消、超时或模型失败都会取消房间，晚到的模型输出不能重新激活房间。取消的局不计入识别率。

## 分身材料

从一页个人资料和约三十组精选对话开始。对话示例建议写成“朋友：…… / 我：……”并保留当时上下文、标点和表情习惯。共同经历只填可以用于游戏的事实；模型被要求在无依据时自然表达不确定。

仅使用专门填写在游戏中的材料，不自动导入已有私聊或研究数据。朋友进入时会看到游戏包含 AI，以及聊天由本人或配置的模型处理的说明。默认使用本机模型，不将聊天内容发送到云端服务。

## 模型配置

默认无需配置或密钥：运行 `npm run model:setup` 一次，下载项目内 Ollama 和 Qwen3.5 4B。以后 `npm run dev` 自动启动已安装的本地运行时，退出时只关闭由本项目启动的进程。也可用 `npm run model:start` 单独启动。模型准备后，主持人页面会自动检测模型是否就绪。

macOS 便携运行时固定为 Ollama v0.33.3，下载后核验 SHA-256；优先复用已安装的 Ollama。项目自行启动服务时禁用云端功能，只绑定本机地址。参考 [Ollama 原生聊天接口](https://docs.ollama.com/api/chat) 和 [Qwen3.5 4B](https://ollama.com/library/qwen3.5:4b)。模型约 3.4GB；首次安装需联网，后续聊天在本机处理。小模型是否像本人需要真实样本与试玩验证。

需要修改默认值时可在 `.env` 设置：

| 变量 | 用途 |
| --- | --- |
| `PLAY_MODEL_PROVIDER` | 默认 `ollama`，可显式设为 `compatible` 接其他接口 |
| `PLAY_MODEL_BASE_URL` | 默认 `http://127.0.0.1:11434`；兼容模式填 API 根地址，包括必要的 `/v1` |
| `PLAY_MODEL_API_KEY` | 本地 Ollama 不需要；兼容模式需要，只保存在服务端 |
| `PLAY_MODEL_NAME` | 默认 `qwen3.5:4b`，也可用已下载的其他本地模型 |

Ollama 模式只允许本机地址，拒绝云端模型别名。使用原生 `/api/chat`，关闭 thinking，最多等待六十秒。兼容模式使用非流式 `/chat/completions`，远程地址要求 HTTPS，最多等待三十秒。两种接口均限制输出长度，不调用工具、不做隐式重试、不记录请求正文或供应商错误内容。此接口独立于原正式研究 provider，配置它不会启用正式研究。

模型未就绪时主持人可登录和整理资料，创建邀请会被阻止。模型错误向朋友统一呈现为本局结束，不用固定话术冒充真实 AI 结果。自动化测试使用模拟的供应商响应，不消耗外部模型额度。

## 核心验收

- 用不同浏览器分别完成本人局和 AI 局，五轮后提交猜测并揭晓。
- 猜测前的朋友 DTO 只含公开消息和轮次，没有 mode、模型名称、分身资料、答案或账号凭证。
- 朋友无法读取其他房间，也无法调用主持人回复入口。
- 重复发消息、刷新、重复猜测与并发请求不改变本局身份和顺序。
- 主持人离线或房间取消后，未完成的模型请求不得落入聊天记录。
- AI 误判率 = AI 局猜本人的次数 / 已揭晓 AI 局数；本人识别率 = 本人局猜本人的次数 / 已揭晓本人局数。无样本显示空值。

运行 `npm test`、`npm run test:play`、`npm run test:portals`、`npm run typecheck` 和 `NEXT_DIST_DIR=.next-build npm run build`。数据库测试使用独立临时 schema，不操作用户的正式记录。运行前启动本地数据库（可通过 `npm run dev`）。

完成生产构建后，可运行 `node --import tsx scripts/smoke-play.ts` 做真实本地模型的 HTTP 验证。脚本在独立临时 schema 和 3305 端口中完成一局本人、一局 AI，检查消息重试、五轮限制、猜测揭晓和统计，退出时清理测试数据。需要本地数据库与 Ollama 已运行。

2026-09-10 本机验收：73 项自动化测试、TypeScript 检查与生产构建通过；真实 Qwen3.5 4B 完成五轮回复，两局共十轮消息全部送达。浏览器验证了主持人登录、邀请、朋友加入和本人回复，检查了桌面布局与手机宽度的注册页。测试使用虚构人物，不能据此判断分身是否像你，需填写自己的样本后试玩。

当前开发服务仅供本机访问。让其他设备上的朋友使用，需要另外配置可访问的地址、HTTPS 与对应的来源配置；本轮未发布到公网。
